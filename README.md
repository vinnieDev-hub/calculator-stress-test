# calculator-stress-test

Calculadora em Python com:
- operações matemáticas básicas
- tratamento de erros
- modo de teste automático
- teste de estresse
- contraprovas matemáticas

## Funcionalidades

### Calculadora normal
- Soma
- Subtração
- Multiplicação
- Divisão
- Tratamento de divisão por zero

### Modo de teste
O sistema executa:
- testes automáticos
- validações matemáticas
- contraprovas das operações
- testes de estresse em intervalos numéricos

## Tecnologias
- Python 3
